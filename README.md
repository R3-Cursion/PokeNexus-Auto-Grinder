This is a vibe coded project.
It runs with python.

	Requirement:

1.Python 3.11.3 (Recommended)

2.Add Python to your system's environment variables (Recommended)

	Instructions:

1.Fork and clone the repositry. 

2.Add pokemon images and name them as "target_1","target_2","target_3",etc.

3.Add rare pokemon popup image and name it as "base_image_rare_pokemon",and a battle screen and name it as "reference_frame" 

4.Open Command Prompt and do pip install opencv-python numpy pyautogui keyboard pyserial". (Or skip these if you have already installed them.)

5.Open Arduino IDE, on library, use the search bar, type and U8g2. Find the library named U8g2 (by oliver) and click Install. Then upload the code (arduinoCode) to your Arduino board.(It needs a screen to work. Me, myself is using an 1.3' OLED Display Module 1.3 inch White/ Blue OLED Display, and an Arduino UNO R3)

6.Run Command Prompt and do "python PokeNexusAutoGrinderV0.1.3.py"

7.Switch to the game.
